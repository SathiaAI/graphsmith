# GraphSmith v0.3.0 — Consolidated Security-Tier Hardening Summary

> Published record of the cross-family adversarial hardening of the v0.3.0 GSA attestation core + regulated register. Each component was built by one family (Anthropic / claude-opus) and adversarially tested by **different, non-Anthropic families**; the orchestrator re-ran every suite (never trusting a transcript), and every finding was fixed or adjudicated against the live code. Per-component detail lives in each `tests/**/ADJUDICATION.md`.

## Method (the discipline these results rest on)
- **Builder ≠ tester.** No component was certified by the family that wrote it. Security-tier components were tested by **≥2 non-Anthropic families** (Codex/GPT via OpenAI, DeepSeek, Mistral-Large, Qwen via OpenRouter).
- **Executed, not reviewed.** Testers authored runnable adversarial suites; the orchestrator ran them. A zero-finding *review* is treated as invalid — only executed pass/fail counts.
- **Two-sided validation gate.** Both findings *and* tester verdicts were checked against the live code. Findings that did not reproduce were adjudicated as false-positives, with the reason recorded. Broken tester suites (a self-referential scope bug, a broken counter) were discarded rather than repaired, to preserve tester independence.
- **Orchestrator probes.** Where a finding was ambiguous (e.g. prototype pollution on the activation guard), the orchestrator ran an independent probe to confirm the real attack was defended.

## Tally
**16 real defects** found by non-Anthropic families and fixed (each re-verified by orchestrator re-run): **1 CRITICAL** (Sybil), **4 HIGH** (RSA-PSS sign, invalid-coverage coercion, algorithm confusion ×2), **11 MEDIUM**. Plus one defensive hardening (SoD fail-closed on a malformed proposer). Zero were found by LLM *review* — two families independently returned "clean" on the very module whose executed suite then found nine bugs. That gap is the case for the discipline.

## Threat classes exercised (and defended)
Signature bypass / strip / replace / untrusted-signer · **algorithm confusion** (declared algo ≠ key type) · manifest + artifact tamper (hash-bound, tamper-evident) · **contradictory bundle** (control-attestation lie) · profile confusion (unearned profile downgraded, never green) · path traversal / backslash / non-NFC · canonicalization (key-reorder, distinct-manifest-same-hash) · **N-of-M Sybil** / separation-of-duties bypass · manual-only-marked-covered (PB-8 fail-open) · broken hash-chain / reorder / truncation · registry-lies air-gap · prototype pollution (own-property reads) · crash-on-malformed (fail-closed, never throws).

## Honest scope
This is adversarial review of *tested behavior* — a floor, not proof of security, and never evidence of compliance. It covers architecture-level resistance, not model-level jailbreak (routed to dedicated tools via the external-tool seam). Full boundaries are in [`KNOWN-LIMITATIONS.md`](../../KNOWN-LIMITATIONS.md). The 3-OS CI matrix and the independent-implementation rows of [`GSA-CONFORMANCE.md`](../GSA-CONFORMANCE.md) remain open — the conformance kit exists so others can fill them.

## Verdict
Every v0.3.0 security-tier component is **TEST-PASSED** by ≥2 non-Anthropic families with an orchestrator-verified trail; the regulated-mode activation guard — the credibility-critical fail-closed heart — holds under executed attack and an independent pollution probe. Dissent and adjudication are preserved per component; nothing was averaged.
