## Headline
v0.3.0 delivers the **GraphSmith Attestation (GSA)** standard — an open, signed, replayable, tamper-evident record of what an AI workflow run actually did — plus the **regulated register** and **air-gapped verification** that v0.2.0 deliberately deferred. *MCP connects agents; GSA proves what they did.* Evidence, **not** certification.

## What's new
- **GSA attestation standard** (`GRAPHSMITH-ATTESTATION-SPEC` + `schemas/attestation-bundle.schema.json`): a portable bundle format + a normative §9 verification algorithm. `scripts/gsa-verify` (verifier), `scripts/gsa-produce` (honest-by-construction sealing), `scripts/gsa-plan` (drift/destructive-change detection + deterministic replay). Ed25519 / ECDSA-P256 / RSA-PSS signing; local keypair default (no PKI); profiles **R/E/B/T/G/Q/A/X**, modes standard/deterministic/regulator; five recomputed control attestations (a contradictory bundle does not verify).
- **The regulated register** (four lanes, each TEST-PASSED): approver identity (N-of-M counts distinct signer keys), obligations→controls (recomputed coverage, manual-only never covered), evidence retention (append-only hash-chained), and air-gapped verification (out-of-band maintainer signature; offline verify with no registry trust).
- **Regulated-mode activation guard** (`scripts/gsa-register`): regulated mode activates only when every register precondition holds against a complete, valid register — fail-closed (the PB-8 line).
- **MCP attestation shim** (`scripts/gsa-mcp-shim`): a boundary attestation for **any MCP-speaking agent, with no agent changes** — profile A-boundary (a labeled lesser claim). Verified against agents GraphSmith did not build (Claude Code, Cursor, LangGraph, Devin, Windsurf).
- **Conformance kit + evidence badge** (`scripts/gsa-conformance`): a portable pass/fail battery any verifier runs; the badge names verifier/platform/result, with unavailable never green.
- **Honest-scope docs:** `KNOWN-LIMITATIONS.md`, a worked offline-verify transcript (`docs/examples/offline-verify.md`), `docs/GSA-CONFORMANCE.md`, and a NIST prior-art submission draft.

## Honest scope (binding)
GSA is an evidence layer, not a certification. A valid bundle proves what ran and that the record is unaltered — never that a workflow is safe, correct, or compliant. External single-delivery is **run-once, replay-verified** of recorded effects, not exactly-once (true single-delivery needs the external system's idempotency key). Per-skill filesystem/model/subprocess grant enforcement is targeted for **v0.4.0** (v0.3.0 attests network egress + external-call presence). Trust of a signer's key is the verifier's policy. A privileged local attacker who rewrites the producer, verifier, and keys is out of scope, stated as such. Full boundaries: `KNOWN-LIMITATIONS.md`.
